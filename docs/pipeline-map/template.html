coreloop Pipeline Map

You hold a key and speak, or type a command. The core cleans it up, works out which app it's for, and decides everything it can on its own. A small local model, decider-0.8b, only picks from a list code wrote. A surface (the Windows desktop, a browser, your own app, or the simulated desktop this page runs on) plans the exact steps and carries them out. Nothing the model says is ever typed, clicked or sent.

2 · the layers

Nine layers, each with one job

Each layer only talks to the one below it. The model sits behind a single file (systemone.ts) and every surface behind one contract (surface/contract.ts: view, skills, plan, run), so either can be swapped without touching the core. This branch runs on the simulated desktop; real surfaces live on their own branches.

Where outside context gets injected

The pipeline never reaches out for data by itself. Everything outside the words is handed in, from the live machine or from fixtures. That's why the tests give the same result on any computer.

5 · safety

Rules the code enforces, whatever the model says

The model only picks

It answers multiple-choice questions over options code wrote. Text to paste or type is cut from your own words (spans.ts); URLs, keys and numbers come from parse.ts.

Bad answers are refused

systemone.ts rejects an answer that picks an option it wasn't offered, or whose probabilities don't add up. A malformed answer can't trigger anything.

Destructive or sending means confirm

A sentence starting with close/quit/kill/exit, whatever action it becomes (an answer to a question included), any action marked confirm, and “… and send” become a confirm (policy.ts). The Session holds the surface's exact plan until you say “confirm”, which must be the very next thing said, within 30 s; anything else drops it. Measured: 0 unsafe in every run.

Nothing is sent for you

Typed or pasted words are never followed by Enter unless you said “… and send” and then “confirm”. A surface's own typing can't send, so “… and send” there is asked about, never dropped. Claude Code prompts are put in, not sent.

No guessing

A verb with no matching action (minimize something that isn't a window, delete, click, copy…) gets “I can't … yet” instead of the model's nearest guess. A named app with no matching action never acts somewhere else, and an operation the surface never declared is never decided.

Passwords are off-limits

A field with role password is dropped before anything looks at the items: never offered to the model, never matched, never typed into (items.ts).

Never half a command

“Open Spotify and search for Panther” runs both only when each part is clear and neither is destructive; the second is planned in the app the first opens. Otherwise it asks. Dictated text (“type salt and pepper”) is left alone.

Buttons that buy or delete wait too

Clicking an item labelled like “Place order”, “Delete account” or “Send” needs a spoken “confirm”, whatever the action's own risk (items.ts, policy.ts).

Only you can connect

The core listens on loopback only. A surface needs the per-launch token, the Host must be loopback, and a browser page's Origin must be on an allowlist, empty by default (surface/server.ts). Everything a surface sends is checked before use.

Your profile can't touch safety

A phrase is a rewrite to another command, which still passes every rule; actions can only be turned off, never confirm or cancel; a learned change is kept only if every eval set holds (profile.ts, review/gate.ts).

Surface text stays out

The model only ever sees your words, never window titles, page text or app text from a surface. Page labels reach it only as short options to pick from (at most 16). Small models echo whatever they read back.

6 · what comes next

The engine is out; the surfaces come next

The engine · coreloop-engine 0.1.0

The core, the surface contract v2 and the wire protocol, on npm with no dependencies. It runs in Node and in a browser, takes its profile and its model from the host, and is measured on every eval set with the model and without it.

Learning from use

npm run review turns the journal of real use into proposed changes to your profile. You accept, edit or reject each, and a change is kept only if every eval set holds.

The surfaces

Your own web app through the npm package, then a Windows desktop surface, a browser extension and Linux: each on the same contract, each passing the same conformance suite.

Numbers measured on an RTX 3050 Laptop (6 GB), Windows 11, October 2026.
